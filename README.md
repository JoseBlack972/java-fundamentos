# Java Fundamentos ☕

Repositório criado para estudar e praticar os fundamentos da linguagem Java.

## 🎯 Objetivo

Este projeto reúne exercícios e exemplos desenvolvidos durante meus estudos de Java, com foco na construção de uma base sólida para desenvolvimento Backend.

## 📚 Conteúdos

- Sintaxe básica do Java
- Variáveis e tipos de dados
- Operadores
- Estruturas condicionais
- Estruturas de repetição
- Métodos
- Arrays
- Orientação a Objetos
- Classes e objetos
- Encapsulamento
- Herança
- Polimorfismo
- Interfaces
- Collections
- Tratamento de exceções

## 🛠️ Tecnologias

- Java 25
- Git
- GitHub

## 📁 Estrutura

- src/main/java/Main.java
- src/test/java/
- .gitignore
- README.md

## 🚀 Primeiro programa

O projeto começa com um programa simples que verifica a configuração do ambiente Java.

O programa exibe uma mensagem no terminal confirmando que o ambiente Java está funcionando corretamente.
